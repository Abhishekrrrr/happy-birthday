# Happy Birthday Digital Letter 🎂✨

An interactive digital letter web page built with HTML, CSS, JavaScript, and Canvas Confetti animations.

## Live Demo
When published via GitHub Pages:
https://Abhishekrrrr.github.io/happy-birthday/

## Deployment Instructions
1. Create a repository on GitHub named `happy-birthday`.
2. Add remote & push:
   ```bash
   git remote add origin https://github.com/Abhishekrrrr/happy-birthday.git
   git push -u origin main
   ```
3. Enable GitHub Pages in repository **Settings -> Pages** (Source: `main` branch, `/ (root)` folder).
